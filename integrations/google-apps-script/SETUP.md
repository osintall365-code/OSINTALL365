# OSINTALL365 Gmail intake integration

This bridge uses Google Apps Script to receive website consultation submissions and send them to `osintall365@gmail.com` through the Google account that deploys the script.

Google documents that Apps Script web apps use `doPost(e)` for POST requests and can be deployed from **Deploy → New deployment → Web app**. The web app can execute as the deploying account. citeturn1search0

## One-time setup

1. Sign in to the Google account that owns the OSINTALL365 Gmail mailbox.
2. Open Google Apps Script: `https://script.google.com/`.
3. Create a **New project**.
4. Open `integrations/google-apps-script/Code.gs` in this repository and copy its complete contents into the Apps Script editor.
5. Save the project and give it a name such as `OSINTALL365 Gmail Intake`.
6. Run the `doGet` function once from the Apps Script editor and approve Google's requested permissions. Apps Script determines required authorization from the services used by the script. citeturn2search7
7. Select **Deploy → New deployment**.
8. Select **Web app**.
9. Set **Execute as** the account that owns `osintall365@gmail.com`.
10. Set access so the public website can submit intake requests. Google documents the available web-app access settings and deployment process. citeturn1search0turn1search3
11. Deploy and copy the resulting `/exec` web-app URL.

## Important

- Never place Gmail passwords, OAuth tokens, client secrets, or API keys in this repository or website JavaScript.
- The script only sends intake information to the OSINTALL365 mailbox. It does not authorize engagements, approve pricing, or authorize spending.
- Customer payment is not requested by the intake bridge.
- The existing PayPal.Me destination remains the payment destination for approved engagements only.
- Incoming customer payments do not authorize outgoing spending.

## Final connection

After deployment, the web-app URL must be connected to the website's intake form. Do not substitute a guessed URL; use the exact `/exec` URL generated by Google's deployment dialog.

Google recommends versioned deployments for public use rather than relying on the test/head deployment. citeturn1search4
